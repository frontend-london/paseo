# AGT-592: Paseo v0.9.2 Patch Audit & Adaptation Matrix

## Overview

This document audits the historical patches, bug fixes, and feature contracts adapted to Paseo v0.9.2 on the `code/AGT-592-v092` branch (based on upstream `c67b7158b441bb09026b38d86ae335cc4b49190a`).

Each item is evaluated under the strict criteria:

- **RETAIN**: Kept and integrated cleanly into v0.9.2.
- **ADAPT**: Modified to fit v0.9.2 architecture, permissions, and lifecycle models.
- **DROP-UPSTREAMED**: Already implemented upstream in v0.9.2 in a superior or equivalent manner.
- **DROP-OBSOLETE**: No longer applicable, superseded by new v0.9.2 semantics, or conflicting with intentional v0.9.2 design.

## Upstream v0.9.2 Benefits Preserved

1. **New Permission & Security Architecture (#5296, #5305)**:
   - Full permission request ID handling across `permit ls`, `allow`, `deny`.
   - OpenCode agents execute under granular permission rules as configured.
2. **File Observation & Watcher Optimizations (#5170, c3e1e084a)**:
   - Daemon CPU utilization fixes on unobservable repositories.
   - Bounded watcher workload for late-ignored directories.
3. **Daemon Bootstrap & Lifecycle Robustness (#5306, #5332, #5310, #5315)**:
   - Stale empty `paseo.pid` cleanup on startup.
   - Detailed startup failure cause logging.
   - Resilient UTF-8 BOM parsing and config naming.
4. **Desktop & Editor Integration (#5335)**:
   - Password-protected daemon support for desktop editor bridge.
5. **Memory and Resident Agent Management (9978988e3)**:
   - Prevention of heap growth after session closes while preserving resident error-state retry semantics.
